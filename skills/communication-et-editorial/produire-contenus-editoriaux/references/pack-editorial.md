# Contrat de livraison éditorial

Choisir les pièces selon la demande ; ne pas créer des fichiers vides pour simuler un pack complet.

| Pièce | Contenu vérifiable |
| --- | --- |
| Registre de sources | Affirmations, liens directs, dates, périmètres et réserves |
| Script | Audio et indications visuelles séparés ; durée estimée explicitée |
| Montage | Fichier exporté et source éditable si disponible |
| Sous-titres | SRT/VTT aligné sur la voix réellement produite |
| Couverture | Image au format visé, contrôlée à taille de vignette |
| Métadonnées | Titre, description sourcée, tags et paramètres pertinents |

Pour « 3 bonnes actus », conserver trois sujets réellement vérifiés sur la période retenue et un statut explicite pour les annonces. Le nom de la série n'autorise pas à remplir un sujet manquant par une invention.

Pour une chronique, conserver la thèse, les éléments qui la soutiennent et les objections factuelles utiles. Une conclusion éditoriale peut être tranchée tout en signalant une incertitude déterminante.
